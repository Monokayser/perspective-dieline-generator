# Perspective Dieline Generator 1.1.2

Version 1.1.2 corrects the mobile application mark and dieline preview proportions while preserving project, export, and native Windows Save As contracts.

## Highlights

- Shared scale-independent SVG package mark for compact mobile headers and large onboarding presentation.
- Unclipped icon geometry across light/dark themes, browser engines, viewport sizes, and high-density displays.
- Professional package-engineering artwork for Windows executables, installers, taskbar entries, and shortcuts.
- Aspect-correct editor and print preview sized from the physical artboard dimensions.
- Clear fitted-preview dimensions and aspect ratio without changing physical 1:1 SVG/PDF output.
- Complete GitHub Pages and offline Tauri builds from the same validated React/Vite source.
- Native Windows SVG Save As remains unchanged: choose any available drive/folder and filename, confirm or cancel, and receive actionable path or permission errors.
