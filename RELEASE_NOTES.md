# Perspective Dieline Generator 1.0.0

This release establishes the local-first workflow from perspective package photography to confirmed measurements and editable 1:1 SVG geometry. It includes the public web app, offline-oriented Windows installer configuration, portable payload, sample pack, and documentation.

Known limitations: one photograph cannot reveal hidden dimensions; real-photo accuracy depends on focus, occlusion, reflection, lens distortion, and manual correction. Windows binaries are not Authenticode-signed. Updater signing remains independent and mandatory for published update artifacts.
