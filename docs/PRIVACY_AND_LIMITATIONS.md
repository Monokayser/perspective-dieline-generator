# Privacy and limitations

No image-upload API, account, analytics SDK, advertising SDK, or cloud project sync is used. Web preferences and recovery snapshots stay in local browser storage. Desktop autosave belongs in private application storage; projects live where the user saves them.

Single-view reconstruction is underconstrained. Hidden edges, lens distortion, deformation, material thickness, glue overlap, grain direction, production tolerance, and machinery rules cannot be recovered reliably from one photograph. Estimated, inferred, or calculated values are visually distinguished from confirmed values and never silently promoted.

Validation finds software-level geometry issues; it is not approval from a packaging engineer, printer, converter, brand owner, or regulator. Always prototype and obtain vendor sign-off. The supplied Alamy reference is not redistributed.
