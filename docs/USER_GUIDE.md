# User guide

1. **Upload** a JPG/JPEG, PNG, or WEBP no larger than 25 MiB or 50 megapixels. The original remains in the project while analysis uses a capped working copy.
2. **Detect** the package. Review the ranked family candidates, confidence, and quality warnings.
3. **Correct** every uncertain corner, edge type, and face. Automatic geometry is a proposal, not a manufacturing measurement.
4. **Measure** with a known edge or manually enter dimensions. Confirm every parameter required by the selected template.
5. **Generate** deterministic millimetre geometry. Regenerating a custom structure discards structural overrides only after explicit confirmation.
6. **Edit** panels and line types. Topology-changing operations switch the model to custom mode.
7. **Validate** and select issues to highlight affected objects. Fabricate a physical prototype before production.
8. **Export** editable SVG or `.pdgproj`. PDF/DXF/raster/JSON are enabled only when vector validation has no errors.

Shortcuts: `V` select, `A` direct select, `Ctrl+Z` undo, `Ctrl+Y` redo, `Ctrl+S` project save, `+/-` zoom, `0` fit, `Delete` remove selection, `Esc` close a drawer.

Web saves use explicit downloads. IndexedDB stores recovery only. Desktop projects should be saved to a user-selected folder; uninstallation must not remove those projects.
